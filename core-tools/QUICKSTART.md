# Quickstart — UMD Faculty Data Pipeline

Read this file at the start of every coding session to get oriented.

---

## What This Project Does

Scrapes UMD faculty directory pages, stores structured data in SQLite databases, and consolidates everything into a master CSV for downstream use in the OneClique app.

---

## Key Files

### Documentation (read these for context)

| File | Purpose | Read when... |
|------|---------|--------------|
| `QUICKSTART.md` | This file. Entry point for every session. | Always |
| `CSV_STRUCTURE.md` | Master CSV column definitions, formats, coverage stats, and source DB details. | Working on the CSV or data cleaning |
| `DATA_CLEANING.md` | Known data quality issues and a prioritized backlog of cleaning tasks. | Doing any data cleaning work |
| `SCRAPING_METHODOLOGY.md` | Step-by-step process for scraping a new department (6 phases). | Adding a new department scraper |
| `SCRAPING_ROADMAP.md` | Which departments are done, in progress, or not started. | Planning what to scrape next |

### Scripts

| File | Purpose |
|------|---------|
| `consolidate_to_csv.py` | Reads all `.db` files, parses `extra_info`, normalizes courses, deduplicates by email, writes `tools/umd_faculty_master.csv`. **This is the main pipeline script.** |
| `scrape_*_enriched.py` | Per-department scrapers (physics, biology, chemistry, astronomy, geology, aosc, smith, cs). Each writes to a `.db` file. |
| `run_all_cmns_scrapers.py` | Batch runner for all CMNS department scrapers. |
| `clean_duplicates.py` | Utility to remove duplicate entries from a `.db` file. |

## Common Tasks

### Regenerate the master CSV
```bash
cd core-tools && ../.venv/Scripts/python.exe consolidate_to_csv.py
```

### Scrape a new department
Follow the 6-phase process in `SCRAPING_METHODOLOGY.md`:
1. Explore the department URL with `WebFetch`
2. Download and analyze the HTML structure
3. Download sample profile pages
4. Write the scraper script
5. Test on 10 faculty with `test_faculty.db`
6. Deploy to production DB, then re-run `consolidate_to_csv.py`

### Do data cleaning
Check `DATA_CLEANING.md` for the prioritized backlog. After any changes, re-run `consolidate_to_csv.py` and verify coverage stats haven't regressed.
